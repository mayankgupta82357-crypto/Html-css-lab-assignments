## Complete Table of Practical Assignments

| Assignment No. | Title | Key Concepts & Deliverables | Status |
|---|---|---|---|
| **Assignment 1** | Starting a Git Repository | `git init`, `git config --local`, `index.html`, initial commits, `git log --oneline` | Verified |
| **Assignment 2** | Pushing and Cloning a Repository | `git init --bare`, `git remote add`, `git push origin main`, `git clone` | Verified |
| **Assignment 3** | Your First HTML Page | `first.html`, `headings.html`, `text-format.html`, `<strong>`, `<em>`, `<br>` | Verified |
| **Assignment 4** | Divs, Attributes and a Small Fix | `layout.html`, `attributes.html`, `data-*` attributes, HTML syntax debugging | Verified |
| **Assignment 5** | Links and Images | `home.html`, `portfolio.html`, `portfolio-image.html`, relative paths, `alt` text | Verified |
| **Assignment 6** | Types of HTML Lists | `shopping-list.html` (ul), `canteen-menu.html` (nested ol), `faq.html` (dl/dt/dd) | Verified |
| **Assignment 7** | About Me Page | HTML5 semantic elements (`header`, `nav`, `main`, `section`, `footer`), `#about`, `mailto:` | Verified |
| **Assignment 8** | Sign-Up Forms and Choices | Form controls, linked labels (`for`/`id`), radio buttons, dropdowns, validation | Verified |
| **Assignment 9** | Tables with Headers and Footers | `caption`, `thead`, `tbody`, `tfoot`, cell accessibility (`scope="col"`, `scope="row"`) | Verified |
| **Assignment 10** | CSS Fundamentals | Inline styles, internal `<style>`, external `style.css`, class and ID selectors | Verified |
| **Assignment 11** | Units and CSS Variables | Absolute units (`px`), relative units (`%`, `rem`), `:root` custom properties `var()` | Verified |
| **Assignment 12** | Box Model, Cards and Scrolling | `content-box` vs `border-box`, card component architecture, `overflow: auto` | Verified |
| **Assignment 13** | Flexbox Layouts | Horizontal navigation flexbar, dual-axis centering, `flex-wrap` product cards | Verified |
| **Assignment 14** | CSS Grid Layouts | 3-column equal grid (`1fr`), `repeat(auto-fill, minmax())`, `grid-template-areas` | Verified |
| **Assignment 15** | Responsive Pages with Media Queries | Viewport meta tag, mobile-first design, `@media (min-width: 600px)`, fluid images | Verified |

1. Clone or download this practical repository.
